## 🐛 Troubleshooting

### Build Failed?

**Check logs:**
1. Vercel Dashboard → Your Project
2. Click failed deployment
3. View build logs

**Common fixes:**
- Ensure `vercel.json` is in root
- Check `requirements.txt` exists
- Verify Python version is 3.9

### Function Error?

**Check function logs:**
1. Vercel Dashboard → Functions
2. View real-time logs
3. Look for Python errors

**Common issues:**
- File not found → Check upload directory
- Import error → Check `requirements.txt`
- Timeout → Increase function timeout

### Frontend Issues?

**Check browser console:**
1. Open DevTools (F12)
2. Check Console tab
3. Look for API errors

**Common fixes:**
- CORS error → Check backend CORS settings
- 404 on API → Verify `vercel.json` routes
- Build error → Check `package.json` scripts
